# Aaditya Jadhav — Zero-Gravity Portfolio

A modern, high-performance single-page portfolio website built for **Aaditya Jadhav** (`@Aadistech`) featuring an **antigravity / zero-gravity** aesthetic with continuous floating physics, subtle mouse-move parallax, and 3D glassmorphic cards.

---

## 🌌 Aesthetics & Physics Features

- **Obsidian & Dark Cosmic Blue Palette**: Deep space theme (`#03050c`) layered with ambient nebula clouds (Cyan, Violet, Emerald, Gold).
- **Zero-Gravity Floating Animations**: Continuous, organic floating motion (`y: [0, -10, 0]`, infinite loop with smooth easing) applied across major UI elements.
- **Mouse-Move Parallax**: Dynamic starfield and background elements that smoothly drift away from the cursor in response to real-time mouse movement.
- **3D-Tilting Glassmorphic Cards**: Interactive perspective tilt and glare reflection on hover for featured projects.
- **Interactive Gravity Modulator**: Floating micro-gravity controller allowing users to switch between **Zero-G Orbit (0.00 G)**, **Cosmic Drift (-0.05 G)**, or trigger a **Gravity Impulse Wave**.
- **Glowing Horizon Line**: Ethereal illuminated horizon beam separating the contact section from the minimal footer.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Animation Engine**: [Framer Motion 11](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

The production assets will be generated in the `dist/` directory, optimized and ready for immediate deployment to Vercel, Netlify, or GitHub Pages.
